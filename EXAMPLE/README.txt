Data       : input profiles for CHEASE and MARS-*
Equi       : working directory for running CHEASE, containing sample namelist 
             input and output files
Kink       : working directory of sample MARS-F runs for computing stability 
             of the pressure driven ideal kink mode, containing sample 
             namelist input and output files
RwmFluid   : working directory of sample MARS-F runs for computing stability 
             of the pressure driven RWM, within the fluid theory
RwmKinetic : working directory of sample MARS-F runs for computing stability 
             of the pressure driven RWM, with the MHD-drift kinetic hybrid 
             approach
RmpLin     : working directory of sample MARS-F runs for computing linear 
             plasma response to external RMP fields
RmpQLin    : working directory of sample MARS-F runs for quasi-linear initial 
             value modeling of plasma rotational damping due to the applied 
             RMP field, as well as the associated RMP field penetration into 
             the plasma
Tm         : working directory of sample MARS-F runs for computing the 
             stability of the linear tearing mode.
Memo       : a memo file ``memo.m'', in the form of a Matlab script, recording 
             the key elements of running the above sample cases.
